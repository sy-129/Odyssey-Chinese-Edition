- 预期：关闭长期备份只影响成功提交后的快照保留；中断写入仍能利用紧急快照恢复。
- 实际：还原入口仅根据 keepBackup 标记拒绝访问，中断状态的紧急快照也被挡住。
- 位置：WQResourceTransactions.m 的 restore:allowChanged:error:。
- 复现：备份选项关闭，在 applying 状态退出，再次启动并处理持久事务。
- 修复：只拒绝已经成功 committed 且未保留备份的记录，允许中断记录恢复；新增真实文件测试覆盖正常提交和中断恢复。

## 验证边界

主机测试实际使用原版 WQ 文件读写与临时文件，不签发沙盒令牌。模拟器实际启动应用并操作 UI。
真机 App Group 权限、worse_query 令牌签发、其他应用启动和第三方应用数据写入，不能用模拟器结果代替。
iOS 无法提供其他应用退出事件，也不保证后台定时准点。当前行为为尽力定时检查、持久待还原记录及回到本应用时恢复。
